# ข้อมูลและลิงก์จากคลิปสอน Quantumult X (圈X)

ข้อมูลนี้ถูกคัดลอกและจัดระเบียบมาจากคำอธิบายใต้คลิป (Description) ของวิดีโอสอนการใช้งานแอป **Quantumult X** บนระบบ iOS

---

## 1. ลิงก์ไฟล์ตั้งค่าสำเร็จรูป (Lazy Configurations)
ใช้สำหรับนำเข้า (Import) ไปยังแอป Quantumult X เพื่อตั้งค่ากฎการแยกทราฟฟิก (Split Rules) และกลุ่มกลยุทธ์ (Policy Groups) โดยอัตโนมัติ:

* **EDC-Lazy Configuration:** [คลิกเปิดลิงก์ไฟล์ .conf](https://raw.githubusercontent.com/erdongchanyo/Rules/main/Quantumult%20X/LazyConf/QuantumultX_EDC-Lazy.conf)
* **Orz-3 Configuration:** [คลิกเปิดลิงก์ไฟล์ .conf](https://raw.githubusercontent.com/Orz-3/QuantumultX/master/Orz-3.conf)
* **墨鱼 (Moyu) Configuration:** [คลิกเปิดลิงก์ไฟล์ .conf](https://raw.githubusercontent.com/ddgksf2013/Profile/master/QuantumultX.conf)
* **毒奶 (Poison Milk) Configuration:** [คลิกเปิดลิงก์ไฟล์ .conf](https://raw.githubusercontent.com/limbopro/Profiles4limbo/main/full.conf)

💡 **วิธีแก้ปัญหาดาวน์โหลดล้มเหลว (Timeout):** หากนำเข้าไฟล์ด้านบนแล้วระบบแจ้งเตือนว่าหมดเวลาหรือไม่สามารถเชื่อมต่อเซิร์ฟเวอร์ได้ ให้เติมลิงก์ต่อประสานเพิ่มความเร็วไว้ข้างหน้าสุด ดังตัวอย่างนี้:
`https://ghfast.top/https://raw.githubusercontent.com/ddgksf2013/Profile/master/QuantumultX.conf`
